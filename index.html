BELUM AKTIF
Menghubungkan Open Cloud
Buat key dengan akses minimal, lalu simpan konfigurasi server di Supabase.
1
Buat API key resmiDi Creator Dashboard, pilih API Keys lalu beri akses Assets dengan izin yang diperlukan untuk creator yang akan mengunggah.
2
Simpan secrets di SupabaseDi Edge Functions → Secrets, atur APP_ORIGINS, AUTH_BRIDGE_SECRET, ROBLOX_OPEN_CLOUD_API_KEY, ROBLOX_CREATOR_TYPE, dan ROBLOX_CREATOR_ID. Samakan bridge secret dengan secret di Cloudflare Pages.
3
Akses untuk semua akun DiscordSetiap akun yang berhasil login bisa upload, dengan batas 5 percobaan per Discord ID dalam 24 jam.
4
Batasi creator dan izin keyGunakan tipe user atau group; creator ID diambil dari profil atau halaman grup. Pastikan API key dibatasi ke creator yang sesuai.
5
Periksa status koneksiSimpan secrets lalu segarkan halaman ini. Coba upload hanya untuk audio yang kamu miliki atau berizin.
Panduan aset resmi Roblox ↗
Open Cloud memakai moderation, validasi, dan kuota Roblox. Aplikasi ini tidak melewati pemeriksaan tersebut dan tidak menyimpan cookie Roblox.
