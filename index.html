BELUM AKTIF
Menghubungkan Open Cloud
Buat key dengan akses minimal, lalu tambahkan pengaturan di server tempat aplikasi dijalankan.
1
Buat API key resmiDi Creator Dashboard, pilih API Keys lalu beri akses Assets dengan izin yang diperlukan untuk creator yang akan mengunggah.
2
Atur server dan akses DiscordAtur ROBLOX_OPEN_CLOUD_API_KEY, ROBLOX_CREATOR_TYPE, dan ROBLOX_CREATOR_ID. Izinkan Discord ID yang dipercaya lewat DISCORD_ALLOWED_USER_IDS (pisahkan beberapa ID dengan koma). Simpan semua nilai di environment server.
3
Batasi creator dan izin keyGunakan tipe user atau group; creator ID diambil dari profil atau halaman grup. Pastikan API key dibatasi ke creator yang sesuai.
4
Simpan lalu periksa statusRestart server dan lihat status koneksi di halaman ini. Coba upload hanya untuk audio yang kamu miliki atau berizin.
Panduan aset resmi Roblox ↗
Open Cloud memakai moderation, validasi, dan kuota Roblox. Aplikasi ini tidak melewati pemeriksaan tersebut dan tidak menyimpan cookie Roblox.
