Menyiapkan API key
Buat key resmi dengan izin sekecil mungkin dan batasi ke creator yang sesuai.
1
Buat key di Creator DashboardPilih API Keys dan beri izin Assets yang dibutuhkan untuk jenis upload yang kamu gunakan.
2
Batasi izin dan creatorGunakan key dengan akses minimum dan batasi hanya ke akun pengguna atau grup tujuan.
3
Simpan di form iniPilih jenis creator, masukkan ID-nya, lalu tempel API key di kolom konfigurasi di atas. Jangan kirim API key lewat chat.
